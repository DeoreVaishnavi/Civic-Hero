# CivicHero Phase 5 — Complaint Management

Phase 5 implements the first complete citizen complaint vertical while preserving the monolithic blueprint structure.

## Backend

- Citizen complaint submission with title, description, category, department, ward, address and GPS
- Optional JPEG/PNG/WebP uploads to Amazon S3 (maximum five files, 5 MB each)
- Complaint list, personal list, detail, edit and withdrawal rules
- Public nearby search using a Haversine distance calculation
- Citizen upvote and remove-upvote operations
- Role-scoped complaint visibility for officers, supervisors and administrators
- Complaint dashboard metrics and metadata endpoints
- Timeline entries for create, edit and withdrawal events
- Authenticated image download streamed through the API

## Frontend

- Citizen dashboard metrics and recent complaints
- Complaint submission form with browser geolocation and image previews
- My Complaints search, filters and pagination
- Complaint details, timeline, downloads, edit, withdraw and upvote controls
- Nearby issue discovery

## Security

- S3 object keys are generated by the server
- Original file paths are discarded
- MIME type, extension, file count and file size are validated
- Officers and supervisors are limited to their department/ward scope
- S3 objects remain private and are downloaded through an authorized API endpoint

## Database

No Phase 5 migration is required. The `complaints`, `complaint_images`, `complaint_timelines` and `complaint_votes` tables were created by the Phase 2 database foundation.
