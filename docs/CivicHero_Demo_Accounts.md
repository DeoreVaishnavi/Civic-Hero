# CivicHero V4 Demo Accounts

## Dataset size

- 300 demo complaints by default
- 60 demo citizens by default
- One officer and one supervisor per existing department
- One demo administrator
- Real JPEG evidence photographs
- MP4 before/after demo clips for complaints that reached a resolution stage
