# CivicHero User Manual

## Citizen

Register and verify your email, report an issue with location and photos, track the timeline,
review resolution evidence, approve or reject the resolution, raise a dispute, read alerts,
and view rewards.

## Officer

Open the assigned work queue, accept or reject assignments, add progress updates, upload
resolution evidence and submit work for citizen verification.

## Supervisor

Assign and reassign complaints, monitor workloads and SLA risk, review disputes, order
rework and view department analytics.

## Admin

Manage users and governance data, review AI/fraud cases and appeals, send broadcasts, view
analytics, audit logs, security events, quality readiness and deployment readiness.

## SuperAdmin

Perform Admin functions plus sensitive configuration, security operations, maintenance,
SuperAdmin management and final appeals. Use this role only for privileged tasks.
